# Sai Medical AI Platform v3.5 — Clinical Intelligence Suite

![Sai Medical AI Platform](/static/images/panel.jpg)

**Sai Medical AI Platform v3.5** is a next-generation, high-performance clinical intelligence suite and AI medical consultation workspace powered by Groq LLaMA-3.3 70B models, WebRTC visual pathology scanning, real-time EKG telemetry, drug interaction matrices, and multilingual clinical decision support.

---

## 🌟 Key Features

- 💬 **Multilingual AI Assistant Triage**: Clinical consultation in English, Telugu, Tamil, and Hindi with Web Speech mic input & downloadable PDF transcripts.
- 📷 **Visual Pathology Scanner**: WebRTC camera stream, drag-and-drop lesion photo upload, and animated laser scanning analysis.
- 💊 **Drug Interaction Matrix**: Pharmaceutical molecule lookup and multi-drug interaction safety cross-checks.
- 🧬 **Lab Report Analyzer**: Clinical reference range evaluation for Hb, Glucose, HbA1c, Cholesterol, and Creatinine.
- 🍎 **AI Precision Diet & BMI Planner**: Condition-aware medical nutrition generator for Diabetes, High BP, Kidney Stones, and Weight Management.
- 🩺 **Multi-System Symptom Checker**: Multi-body system diagnostic triage suite.
- 🌐 **Wikipedia Live Medical Library**: Real-time REST API medical terminology lookup.
- 📊 **Real-Time Telemetry Cockpit**: Live consultation tracking and system status monitor.

## 🚀 Quick Start & Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/suryaramisetty70-pyt/sai-medical-agent-.git
   cd sai-medical-agent-
   ```

2. **Install Python Dependencies:**
   ```bash
   pip install flask groq gtts reportlab requests
   ```

3. **Run the Application:**
   ```bash
   python app.py
   ```

4. **Access the Workspace:**
   Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your web browser.
